# OpenCADStudio v1.0.5

This release repairs the coordinate pipeline so Boston, California, and mixed
LAS/LAZ datasets share one explicit drawing coordinate space instead of relying
on regional exceptions.

## CRS and units

- The first referenced LAS/LAZ automatically sets the drawing CRS and working
  units. Full embedded WKT/PROJ definitions are retained when a projected CRS
  has no projected root EPSG authority.
- WKT2 projection methods, parameter aliases, ellipsoids, and length units are
  parsed for common LCC, Transverse Mercator, Mercator, Albers, stereographic,
  azimuthal, and oblique-Mercator datasets.
- Mixed-CRS sources are transformed into the drawing CRS for samples, bounds,
  streamed LOD tiles, derived CAD geometry, coordinate copying, and merged
  export. Horizontal XY is transformed; Z remains unchanged unless the user
  explicitly supplies a separately validated vertical workflow.
- Unreferenced sources can explicitly adopt a user-selected drawing CRS without
  changing their numeric coordinates. Declared but unusable CRS metadata now
  fails visibly instead of being treated as drawing coordinates.

## Basemaps

- Removed the empty-drawing global/area-of-use fallback that could generate
  enormous tile requests. Basemaps now require an actual drawing, cloud, manual,
  or camera-follow extent anchored by project content.
- `BASEMAP BOUNDS` is interactive when called without coordinates; two picked
  corners establish the drawing-coordinate extent.
- Web Mercator requests are clipped to the valid world, exact maximum tile
  edges are exclusive, and interactive loads remain capped at 256 tiles while
  zoom is reduced safely for larger project extents.

## Multi-file LOD and integration

- `POINTCLOUDINDEX` builds or opens every attached source sequentially. A bad
  source is recorded once and skipped for the remainder of the batch, avoiding
  immediate retry loops and allowing later tiles to complete.
- Point-cloud streaming now permits only one dataset batch in flight, while a
  batch may still read up to eight cache files in parallel. Completion and
  error attribution is source-safe.
- Existing cache manifests are transformed into drawing space for visibility
  selection, while raw cache records remain reusable and are transformed as
  they stream.
- Multi-source export reprojects each input into the drawing CRS and writes a
  matching output WKT and safe union coordinate transforms.
- Coordinate-copy conversion uses the complete drawing CRS descriptor rather
  than only an EPSG code.
- Cross-section width is consistently a total screen-pixel width in the UI,
  CPU tile-selection band, GPU uniform, and shader.

## Validation

The release adds regression coverage for custom California WKT1/WKT2 state
plane definitions, Boston false offsets in feet, mixed geographic/projected
point and bounds transforms, exact basemap tile edges, source-independent LOD
batch advancement, unreferenced CRS adoption, and mixed-CRS merged export.
