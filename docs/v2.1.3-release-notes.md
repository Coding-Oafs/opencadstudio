# OpenCADStudio v2.1.3 — discoverable terrain, LiDAR and modeling tools

This release brings the command-only elevation and scene-building features into the interface. It also gives the existing command registry a searchable home.

## Getting started

- **Find tools**, next to the ribbon tabs, searches by task, tool name or command. Try **drape**, **mesh**, **section**, **ground** or **contour**. Choose a tool to read its purpose, fill in its settings and click **Start tool**.
- **Terrain & GIS → Terrain workspace** opens the elevation workflow. Set the drawing coordinate system, enter longitude and latitude and a radius, choose source detail with the slider, and download the site. Alternatively, pick an area in the drawing and reopen the workspace to download it. A completed download creates a terrain mesh.
- To drape geometry, select curves, polylines or meshes in the drawing, reopen the terrain workspace, set spacing and offset, and choose **Drape selection**. The app creates copies and keeps the original objects.
- **LiDAR → Surface products** opens settings for bare-earth elevation (DTM), top-surface elevation (DSM), hillshade, contours and elevation queries. **Drape objects** opens the cloud-terrain draping form. **All LiDAR tools** includes section, classification, display, export and indexing tools.
- **Model → All modeling tools** includes labeled settings for mesh welding, hole filling and face deletion. The Model ribbon also exposes 3D transforms, slicing, sections, press/pull, thickening, interference and mesh diagnostics.

Tools that need objects should be opened after selecting those objects. Starting a tool closes the tool center and opens command history so that the next prompt and the result remain visible. Hover over tools for help. Esc closes the current panel.

## Feature audit and interface coverage

| Area | Gap found in v2.1.2 | Frontend home in v2.1.3 |
| --- | --- | --- |
| Global terrain | Location, source detail, fetch/cancel, mesh budget, elevation query and draping were command-only | Terrain workspace with labeled fields, source-detail slider, progress, prerequisite messages and action buttons |
| Terrain state | Download area and detail settings were shared between drawings; coordinate changes could leave a resident grid in the old coordinate system | Drawing-specific request settings; changing CRS clears the elevation model and bounds and cancels stale downloads |
| LiDAR surfaces | DTM, DSM, hillshade, surface query, draping and breakline tools lacked a clear ribbon home | Surface products menu, drape form and breakline button |
| LiDAR parameters | Several ribbon actions used hardcoded defaults; custom values required commands | Forms for cell size, contour interval, drape spacing/offset/coverage, noise radius, section width/movement, class, color, size and display budget |
| 3D editing | Model tab emphasized primitives, profiles and Booleans | Added transform, cut/section, press/pull, thickening and interference controls; pyramid and wall added to primitive choices |
| Mesh repair | Diagnostics and repair verbs were hidden in dispatch code | Diagnose, orient and flip buttons; weld tolerance, hole-size and face-index forms |
| GIS | Native import required a typed path | Import GIS button with file chooser; GIS/project category in tool center |
| Remaining commands | Command names discoverable mainly through autocomplete | Searchable catalog combines curated tools, existing ribbon actions, registered commands/aliases and loaded plugin command names |
| Help | Ribbon tooltips usually contained only a label and command | Curated descriptions explain purpose, prerequisites and important effects; tool center shows settings and guidance |

The catalog's **Advanced commands** category preserves access to registered commands and aliases that do not yet have an individual form. Those entries still use the existing command prompts or usage messages. Workflow/standards definitions retain their existing advanced JSON editor. This release does not claim a dedicated graphical editor for every advanced command.

## Terrain behavior

- Use the coordinate system supplied with the drawing or survey. An EPSG code assigns the drawing coordinate system; existing CAD geometry is not automatically moved to a different site.
- Higher source zoom requests finer tiles, but source accuracy varies. Large requests can be reduced to remain within the existing 256-tile limit.
- Resident elevation data is session-only. Save the drawing to retain generated meshes and draped objects. Rebuilding adds another mesh; use Undo to remove the latest result.
- Changing or clearing the CRS unloads resident elevation data and cancels its pending download. Existing mesh geometry remains.
- Global elevation is useful for scene context. It does not replace surveyed site measurements.

## Windows package

`OpenCADStudio-2.1.3-windows-x86_64-installer.msi` includes the CAD application, LiDAR classifier, PROJ worker, pinned geoid grid and drawing thumbnail provider. The installer retains the existing Windows upgrade identity. SHA-256 checksums are distributed alongside the installer.
