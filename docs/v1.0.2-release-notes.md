# OpenCADStudio 1.0.2

OpenCADStudio 1.0.2 fixes blank and incorrectly located basemaps in v1.0.1.

## Fixed

- Basemap replacement now invalidates the viewport render cache, ensuring newly
  downloaded tiles are uploaded and drawn immediately instead of reusing a
  blank pre-load frame.
- State-plane WKT coordinates expressed in feet now convert false easting and
  northing parameters to the metre values required by PROJ.4. The Boston USGS
  LiDAR fixture now resolves to approximately 42.316° N, 71.016° W instead of
  requesting ocean tiles near 27° N, 75° W.
- Basemap-only views retain a stable image source while navigating, preventing
  every tile texture from being uploaded again on each pan or zoom frame.

## Upgrade

Install the 1.0.2 MSI over 1.0.1. Drawings and adjacent `.ocspc`
spatial/LiDAR sidecars are preserved.
