# OpenCADStudio v2.0.1 — LiDAR LOD and basemap stability

v2.0.1 is a corrective release focused on stable, bounded point-cloud
rendering and reliable basemap coverage while navigating large survey scenes.

## LiDAR streaming and rendering

- Replaces uniform whole-view LOD selection with hierarchical screen-space
  refinement, allowing coarse and fine octree nodes to coexist without
  ancestor/descendant double drawing.
- Keeps the previous complete multi-source frontier visible until every source
  has loaded the same camera generation, eliminating source-by-source flashes
  and rectangular holes during zoom and rotation.
- Shares one bounded GPU point arena across all viewports instead of allocating
  a separate arena per viewport.
- Enforces fair, deterministic point quotas across sources and hard CPU/GPU
  ceilings after exact section-corridor compaction.
- Rebuilds discard-section geometry when the corridor changes, widens the
  supported map-space section band to 3,072 units, and preserves precision at
  survey-scale coordinates with a local high/low origin split.
- Corrects the class-visibility shader lookup and zero-size discard quad
  placement.

## Tile-cache correctness

- Introduces the rebuildable `.ocstiles-v3` cache format with conservative
  octree-cell bounds so visible descendants are not lost during frustum or
  section traversal.
- Accepts valid mixed labeled/unlabeled records while still rejecting
  truncated, padded, or inconsistent tile streams.
- Reuses valid v3 caches and safely ignores obsolete manifests.

## Basemap stability

- Computes camera-follow coverage from viewport-corner ground intersections,
  including orbit and perspective views, with bounded horizon fallbacks.
- Reprojects imagery as tessellated tile meshes so rotation, shear, and curved
  edges survive target-CRS conversion without gaps or overlaps.
- Uses a trailing-edge refresh debounce so navigation fetches the final camera
  view rather than dropping it.
- Requests an explicit English/US Google Hybrid locale and isolates the new
  response namespace from older localized cache entries.

## Verification

- 70 `ocs_pointcloud` unit tests.
- 5 point-cloud shader contract tests.
- 3 app-level LOD tests, 10 basemap tests, and the tessellated-image UV test.
- 5 platform tests and 10 spatial/geodesy tests; the packaged-PROJ integration
  test remains a release-workflow gate.
- Complete desktop `cargo check` and targeted formatting checks for every
  changed Rust source file.

Existing `.ocstiles` and `.ocstiles-v2` directories are not modified. The app
builds a separate `.ocstiles-v3` cache on demand.
