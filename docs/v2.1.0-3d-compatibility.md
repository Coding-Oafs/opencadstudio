# OpenCADStudio v2.1.0 3D compatibility matrix

| Area | v2.1.0 support | Limits / fallback |
| --- | --- | --- |
| 3MF Core import | Meshes, build items, nested component transforms, units, object names, base-material colors | Required unknown extensions are rejected; textures and slicer metadata are reported but not imported |
| 3MF export | Exact CAD MESH vertices/faces, units, layer names, RGB base materials, atomic replacement | Component hierarchy is flattened because the CAD document does not yet persist a 3MF assembly graph |
| Large mesh display | Exact LOD 0 plus generated display-only LODs above 50,000 triangles | Editing always targets exact source geometry; interactive repair commands cap adjacency-heavy edits at 1M faces |
| Mesh repair | Diagnose, exact/tolerance weld, fill bounded holes, flip/orient winding, delete faces | Sub-object hover overlays and decimated working-region UI are post-v2.1.0 |
| Terrain surfaces | Full-density DTM/DSM/hillshade raster jobs with project provenance and source fingerprints | Full-density constrained TIN persistence is post-v2.1.0 |
| CAD draping | Lines, arcs, circles, ellipses, splines, closed footprints, 2D/3D polylines, mesh copies | Interactive drape uses resident class-2 points (or reported all-point fallback); mesh copies cap at 1M vertices |
| Breaklines | Selection ingestion and validation for crossings, duplicates, zero-length segments, and grade spikes | Constrained-Delaunay rebuilding is post-v2.1.0 |
| Surface inspection | XY elevation and signed point-to-surface distance; named cross-section workflow | Cut/fill profiles and surface-difference heat maps are post-v2.1.0 |
| Spatial reference | Drawing/project CRS, vertical metadata, transformation policy, and local render origin | 3MF has units but no standard geodetic CRS payload; it inherits the drawing/project context |
| Resource control | Mesh display LODs, point budgets, bounded tile uploads, full-density streaming rasterization | GPU occlusion culling is post-v2.1.0; frustum/LOD fallback remains active |
| Windows package | x64 MSI, DWG/DXF/3MF associations, thumbnail helper, LiDAR/PROJ workers | Package signature depends on release signing credentials; unsigned builds remain hash-verifiable |

The release gates use both deterministic fixtures and the 50.9 MB Boston HIGH
3MF model. Features listed as post-v2.1.0 are deliberately excluded from the
release claim rather than exposed in a partially safe state.
