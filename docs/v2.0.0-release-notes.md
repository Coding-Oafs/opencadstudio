# OpenCADStudio v2.0.0 — Integrated Engineering Platform

v2.0.0 completes the local-first engineering platform planned after v1.1.

## Workflows and standards

- New Manage-ribbon visual workflow builder with graph preview, JSON editing,
  registry validation, deterministic DAG ordering, and `.ocsproj` persistence.
- Company standards manager with templates, rule previews, import/export,
  SHA-256 sealing, Ed25519 verification, and project-scoped signer trust.
- Unified cross-domain transactions, workflow runs, standards, provenance, and
  validation profiles persist in schema-2 spatial projects.

## LiDAR and 3D delivery

- Full-density, disk-backed octree 3D Tiles export from the LiDAR manager.
- Source coordinates are converted to WGS84 Earth-centered coordinates; PNTS
  leaves remain bounded and clients can request assets lazily and safely.
- Real LAS/LAZ release smokes now run in CI. Their first execution fixed LAS vs
  LAZ merge compatibility, LAS public-header offsets, and LASzip VLR handling.

## Survey geodesy

- Bundled isolated PROJ 9 worker with pyproj 3.7.2.
- Official NOAA GEOID18 grid `us_noaa_g2018u0.tif`, pinned to SHA-256
  `fa9a407ac7ee3f5a3694008e4bcd09ce9cc250452f0c3b11700a4960340abce2`.
- Grid transforms fail closed if the worker or verified resource is missing.
  Windows MSI/portable, AppImage, and macOS packages include the backend.

## Updates and networking

- The updater now follows the Coding-Oafs release feed and compares SemVer, so
  an installed v2 prerelease is never offered an older v0.x release.
- OpenCADStudio keeps its IPv4-first resolver workaround while the narrow
  multi-address fallback fix proceeds upstream in ureq.

## Verified release gates

- Desktop compile/check and core unit/integration suites.
- Workflow/standards and octree streaming tests.
- Bundled PROJ self-test plus real checksum-pinned GEOID18 transformation.
- Three real-data LiDAR smokes over 220,000 LAS/LAZ records.
- Two-million-point release stress test in the release workflow.
