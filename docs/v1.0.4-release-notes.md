# OpenCADStudio v1.0.4 local test build

This local Windows test build keeps the complete v1.0.3 CAD and LiDAR platform
and adds a packaged Boston urban point-cloud classification macro.

## LiDAR classification workflow

- Added **Urban Classify** to the LiDAR ribbon and classification controls to
  the LiDAR Point Cloud Manager.
- Added `POINTCLOUDURBANCLASSIFY CURRENT` and
  `POINTCLOUDURBANCLASSIFY FOLDER` command-line entry points.
- Bundled the classifier and its geospatial runtime as
  `ocs-lidar-classifier.exe`; the installed workflow does not require Python.
- Processes source LAZ at full density and writes separate outputs in a sibling
  `classified` folder. The source files are never modified.
- Automatically detaches the source and opens the finished classified tile or
  folder for immediate class-color inspection.

## Classification profile

- Uses official Boston building footprints, official roadway data, and active
  Boston street-tree locations.
- Adds a conservative vegetation class using a 12-foot active-tree radius.
- Writes ASPRS display classes for ground (2), vegetation (5), building (6),
  water (9), rail (10), road (11), bridge (17), and noise (18).
- Retains the UPCP-style `label` extra dimension and preserves the original
  ASPRS class byte in `source_classification` for auditing or rollback.
- Adds Vegetation (ASPRS 5) to the manual classification controls.

This is an unsigned local test package. No GitHub release, tag, or publishing
workflow is run for this build.
