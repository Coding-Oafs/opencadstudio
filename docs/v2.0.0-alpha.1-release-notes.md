# OpenCADStudio v2.0.0-alpha.1 — Integrated Platform Core

This alpha establishes the durable contracts required for v2 without claiming
the remaining production UI and release gates are complete.

## Unified transactions

- Typed identifiers cover CAD entities, GIS features, source points, rasters,
  surfaces, meshes, and domain model objects.
- Cross-domain create/update/delete transactions carry before/after snapshots.
- All preconditions are checked before mutation; a rejected change rolls back
  changes already applied by the transaction.
- Inverse transactions provide a data-engine-neutral undo record.

## Workflows and company standards

- Versioned workflow graphs validate tool availability, missing nodes,
  duplicate edges, and cycles before execution.
- Parameter bindings consume named upstream outputs, and every node executes
  once in deterministic topological order.
- Company standards packages carry tool presets and validation rules.
- Package content is sealed with SHA-256 and optional Ed25519 signatures are
  verified against project-trusted public keys.

## Provenance and delivery

- Provenance records capture tool/API/software versions, environment digest,
  input/output artifacts and hashes, object ids, parameters, transformations,
  duration, and result status.
- The platform state is persisted in `.ocsproj` schema 2. Schema-1 projects
  load with an empty platform state and upgrade on their next atomic save.
- A restart-safe 3D Tiles 1.0 point exporter writes `tileset.json` plus PNTS
  content with RTC coordinates and a real bounding volume.

## Alpha limitations

- The visual workflow editor and standards-management UI are not built yet.
- The current 3D Tiles exporter produces one bounded point tile; octree
  partitioning and streaming endpoints remain to be added.
- Optional enterprise collaboration, plugin marketplace signature enforcement,
  and reproducible environment locking remain release gates.
