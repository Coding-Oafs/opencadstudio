# Open CAD Studio 2.1.2 — global terrain elevation

This build adds real-world terrain to 3-D modelling: `TERRAIN` fetches global
bare-earth elevation for a drawing area and turns it into a modelable mesh
plus a resident surface for draping and elevation queries.

## New: TERRAIN command family

- **Data source.** AWS Terrain Tiles ("terrarium" tiles, the Mapzen global
  data set on the AWS Open Data program): free, no account or API key, global
  coverage, roughly 30 m bare-earth resolution (SRTM/GMTED-derived), heights
  in meters relative to mean sea level. Data © Mapzen contributors and AWS.
  Google's Elevation API was deliberately not used: its terms of service
  prohibit building terrain models from the data.
- **`TERRAIN AREA <longitude> <latitude> [radius-km]`** (or the ribbon
  "Terrain Area" tool) fetches elevation around a site. Requires a drawing
  CRS (`CRS <epsg>`), like the basemap.
- **`TERRAIN BOUNDS [minx miny maxx maxy]`** fetches a drawing-coordinate
  envelope; omit the coordinates to pick two corners. Bare `TERRAIN FETCH`
  covers the current drawing/basemap extent.
- The fetched grid is resampled into the drawing CRS (square cells in drawing
  units; elevations converted to the CRS coordinate unit — meters or feet)
  and committed as a **3-D mesh entity** through the normal undo flow
  (`TERRAIN MESH [max-vertices]` rebuilds it, default 400 k vertices).
- The same grid stays resident as a **drape surface**:
  - `TERRAIN DRAPE [spacing] [vertical-offset] [ABORT|SKIP|CLAMP]` drapes the
    selection onto the terrain.
  - `POINTCLOUDDRAPE` falls back to the terrain model when no LAS/LAZ cloud
    is attached.
  - `TERRAIN INFO [x y z]` reports the elevation under a point with the
    signed vertical distance from the picked Z.
- **Resolution controls.** `TERRAIN ZOOM <0-15>` picks the source tile zoom;
  `TERRAIN RES <zoom | cell-size-in-drawing-units>` targets a cell size
  instead. `TERRAIN STATUS` reports progress and the resident model,
  `TERRAIN CANCEL` stops a fetch, `TERRAIN REMOVE` clears it.
- Tiles are disk-cached under the OpenCADStudio config directory
  (`terrain_cache`), so refetching a site is offline and instant.

## Accuracy notes

- The global data set is bare-earth ~30 m — suitable for site context,
  conceptual grading and visualization, not survey-grade design.
- Heights are relative to mean sea level as published per source tile;
  no geoid model is applied (Z passes through the CRS transform unchanged).
- Degree-based (geographic) drawing CRSs keep elevations in meters.

## Packaging

Built with `scripts/build-windows-msi.ps1` as in 2.1.1; the MSI upgrades
installed 2.x versions in place.

## Verification

82 `ocs_pointcloud` crate tests (including the new batch-reprojection
contract), 567 application tests (including 14 new terrain unit tests:

unit heuristics), plus the platform/spatial/shader contract suites.
