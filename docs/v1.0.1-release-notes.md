# OpenCADStudio 1.0.1

OpenCADStudio 1.0.1 is an urgent basemap stability patch for v1.0.0.

## Fixed

- Prevented an out-of-memory native abort when enabling imagery, changing the
  basemap projection, or refreshing imagery over an empty or large drawing.
- Tile coverage is now counted before any request vector is allocated. A
  full-world zoom-22 envelope (over 17 trillion theoretical tiles) is handled
  as a constant-memory count instead of an attempted allocation.
- Large drawing extents automatically use a lower effective overview zoom,
  capped at 256 tiles. Empty-drawing/CRS-area bootstrap views remain capped at
  64 tiles.
- The configured detail zoom is retained for later, smaller site extents; only
  the current oversized request is reduced.

## Spatial bootstrap workflow

No LiDAR or CAD geometry is required:

1. Enable a basemap to see the world overview.
2. Set `CRS <EPSG>` to show that CRS's area of use.
3. Use View → **Set Location**, or enter
   `BASEMAP CENTER <longitude> <latitude> [radius-km]`.

## Upgrade

Install the 1.0.1 MSI over 1.0.0. The WiX package performs an in-place upgrade;
drawings and adjacent `.ocspc` spatial/LiDAR sidecars are preserved.
