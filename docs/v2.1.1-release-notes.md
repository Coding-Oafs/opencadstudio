# Open CAD Studio 2.1.1 — reliability and usability review

This maintenance build includes the existing 2.1.0 workspace improvements and
the following fixes from the September 5 review.

- **Safer Windows saves.** A failed replacement no longer deletes the original
  drawing before attempting a rename. Transient sharing/locking failures receive
  bounded retries; persistent failures preserve the original and report an error.
- **Background operations.** Saving and update checks now await background work
  without blocking the async executor. Import/export/printing worker panics and
  thread-start failures become ordinary error results.
- **Plot style editing.** Invalid or pasted Unicode color values cannot crash the
  editor or silently become black. Invalid screening and lineweight input is
  reported before applying any changes. Legacy CTB color parsing uses the same
  validation, and decompression stops at 16 MiB to bound malformed-file expansion.
- **Drawing isolation in automation.** NEW and successful OPEN create fresh
  document state, clearing the old history, selection, UCS, caches and edit lease.
  The new state adopts the drawing's saved current layer. A failed OPEN keeps
  the existing drawing and history.
- **Update notifications.** The existing JSON library now reads top-level fields,
  whitespace and Unicode correctly, including emoji in release notes.
- **Installer reliability.** Manual CI builds use the manifest version instead of
  0.0.0. The new local build script rejects mismatched executable versions and
  missing/broken processing workers, and verifies the bundled PROJ grid checksum.

## Local packaging

Unpack the official WiX 3.14.1 portable binaries into `target/tools/wix`, or pass
another WiX 3 directory with `-WixBinDir`. The existing bundled classifier, PROJ
worker and grid must be in `target/release`; their build recipes are in the release
workflow. Then run from the repository root:

```powershell
./scripts/build-windows-msi.ps1
./scripts/smoke-windows-release.ps1 -ExePath ./target/release/OpenCADStudio.exe
./scripts/verify-windows-msi.ps1 -MsiPath ./dist/v2.1.1/OpenCADStudio-2.1.1-windows-x86_64-installer.msi
```

The script builds the application and thumbnail DLL, validates the workers,
links the MSI, and writes SHA-256 checksums under `dist/v2.1.1`. On a machine
where Windows Installer ICE validation is unavailable, it suppresses only that
WiX validation stage; `verify-windows-msi.ps1` performs independent metadata,
association, cabinet and payload checks.
`-SkipBuild` supports repackaging an already-built matching executable.

The MSI retains the existing upgrade identity, optional desktop shortcut and
DWG/DXF/3MF associations. This local build does not add a signing certificate or
publish a GitHub release.
