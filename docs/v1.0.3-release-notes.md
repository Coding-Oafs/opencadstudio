# OpenCADStudio 1.0.3

OpenCADStudio 1.0.3 integrates the original project's v0.9.7 release into the
1.0.2 LiDAR platform. It keeps the point-cloud, basemap, CRS, scripting, tool
palette, sheet-set, and cross-section work from the 1.0.x line while adopting
the upstream CAD, rendering, plugin, localization, and packaging improvements.

## CAD and editing

- Expanded spline creation, editing, grips, control-polygon display, projection,
  and tessellation behavior.
- Improved multi-window STRETCH selection plus fixes across TRIM, FILLET,
  OFFSET, LENGTHEN, BREAK, JOIN, and EXPLODE workflows.
- Added the upstream hatch and gradient pipeline, including stronger boundary,
  island, editing, export, and rendering support.
- Integrated the revised REVCLOUD, SKETCH, and WIPEOUT commands and their
  interactive command-state fixes.
- Brought in upstream fixes for dimensions, leaders, tables, text, blocks,
  layers, properties, inquiries, and 3D primitive operations.

## Rendering and scene model

- Integrated the upstream frame and block-instance rendering architecture,
  including dedicated block wire, text, and face pipelines.
- Added mesh optimization, silhouettes, and updated mesh, shadow, hatch, image,
  text, and wipeout rendering paths.
- Improved solid and curve tessellation with view-sensitive chordal deflection,
  while retaining the 1.0.x GPU point arena used by LiDAR datasets.
- Preserved large-raster downscaling and the 1.0.2 basemap cache/CRS corrections.

## Plugins and automation

- Added plugin API v4, typed registration, shared-memory transport updates, and
  the v4 client/server process layer while retaining earlier plugin support.
- Kept the 1.0.x Rhai scripting system and JSON automation API integrated with
  the upstream command and document changes.
- Preserved safe edit leases and drawing fingerprints when opening, automating,
  saving, and recovering drawings.

## Interface, files, and distribution

- Adopted the generalized dock system for Properties and Blocks and reconciled
  it with the 1.0.x Tool Palettes and Sheet Set panels.
- Added upstream read-only UI behavior, keyboard selection improvements, start
  page resources, and expanded translations and localized readmes.
- Integrated plotting, page-setup, annotation-unit, recovery, and drawing-save
  fixes without changing `.ocspc` LiDAR/spatial sidecar compatibility.
- Fixed timed autosave so internal `.sv$` recovery files are accepted and
  written as valid DWG data without broadening the formats offered by Save As.
- Fixed LiDAR cache restoration so valid adjacent `.ocstiles` caches are
  discovered and activated immediately, and duplicate source attachments are
  rejected before they consume another point budget.
- Added Snap packaging and refreshed Windows, Linux, macOS, and web release
  workflows from the upstream release.

## Upgrade

Install the 1.0.3 MSI over 1.0.2, or replace the portable executable. Existing
drawings, settings, scripts, and adjacent `.ocspc` sidecars are preserved.

Upstream integration source:
[HakanSeven12/OpenCADStudio v0.9.7](https://github.com/HakanSeven12/OpenCADStudio/releases/tag/v0.9.7).
