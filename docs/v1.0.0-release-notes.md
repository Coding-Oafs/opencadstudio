# OpenCADStudio 1.0.0

OpenCADStudio 1.0 turns the v0.9.7 LiDAR platform into a cohesive production
desktop workflow. The release focuses on reliability, spatial context,
measurement, and discoverable viewport interaction while preserving the full
v0.9.7 multi-source history.

## Highlights

- Fast, cancellable basemaps with bounded parallel loading, persistent disk
  caching, visible progress/failure counts, stale-result rejection, and an
  empty-drawing world/CRS-area bootstrap with a project-location command.
- Drawing-owned EPSG CRS and working units, independent of LiDAR, with status
  bar/ribbon controls and sidecar v4 persistence.
- Length, area, closed-mesh volume, and snapped point-cloud distance tools in
  the Annotate/LiDAR ribbons and tool palettes.
- Dedicated Select and Navigator tools; Navigator combines wheel zoom,
  left-drag pan, and Shift+left-drag orbit.
- LiDAR manager, multi-file/folder data sets, LOD streaming, GPU arena,
  viewport point/box/fence/brush selection, sparse edits and undo,
  ground/noise/rule classification, DTM contours, CRS-safe reprojection, and
  merged export.
- Release-gate fixes for zero-sized GPU shards and analytic sphere rendering/
  volume tessellation.

## Spatial commands

- `CRS <EPSG|LAS|UNSET>`
- `WORKINGUNITS <METERS|CENTIMETERS|FEET|INCHES>`
- `SPATIALINFO`
- `BASEMAP CENTER <longitude> <latitude> [radius-km]`
- `BASEMAP BOUNDS <minx> <miny> <maxx> <maxy>`
- `BASEMAP PROJ DRAWING`

## Measurement and interaction commands

- `DIST`, `AREA`, `MEASUREGEOM`, `VOLUME`
- `POINTCLOUDMEASURE`
- `SELECTTOOL`, `NAVIGATOR`

## Upgrade notes

- Existing v2/v3 `.ocspc` sidecars migrate automatically to schema v4.
- Drawing CRS, working units, and manual basemap bounds are stored adjacent to
  a saved drawing in `<drawing>.ocspc`; source DWG/DXF geometry is not silently
  rescaled.
- Working units are free when no CRS is set. Once a CRS is assigned, the unit
  is normalized to the CRS horizontal coordinate unit.
- The MSI supports in-place upgrades and installs the DWG thumbnail provider,
  `.dwg`/`.dxf` associations, application icons, and Start Menu shortcut.

## Known limits

- Cache size eviction/conditional revalidation, COPC/E57, raster DEM export,
  watched-folder queues, and point-to-plane/cloud-to-cloud statistics remain
  post-v1 work.
- macOS artifacts are ad-hoc signed and not notarized; Windows signing depends
  on the repository's Trusted Signing secrets.
