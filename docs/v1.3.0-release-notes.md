# OpenCADStudio v1.3 — Reality to Model Core

The `ocs_reality` crate supplies deterministic, full-density mathematical
building blocks for reality-derived engineering geometry:

- Least-squares terrain/roof plane fitting with RMS and maximum residuals.
- Least-squares sphere fitting.
- Principal-axis linear extraction for curb, rail, paint-line, and wire
  candidates.
- Three-dimensional alignment stationing with signed plan offset.
- Raster surface comparison with cut, fill, min/max/mean delta, and per-cell
  change values.
- Nearest-distance point-cloud change classification.
- Convex-hull LOD1 building reconstruction using a robust median roof height.
- Typed tool descriptors declare full-source density, CRS, cancellation,
  checkpoint, background, and derived-output behavior.

These algorithms do not read display samples or resident viewer tiles. The job
engine must supply the requested processing extent at full source density.

This stage is the reusable analysis core. Interactive extraction editors,
strip-alignment UI, roof segmentation, cylinders, meshes/solids, and domain
corridor objects remain later production work.
