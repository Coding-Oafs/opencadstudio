# OpenCADStudio v1.0 reviewed implementation and release plan

Status date: 20 August 2026
Release line: `v0.9.7-lidar-platform` → fast-forward `main` → `v1.0.0`

## Review outcome

The attached v0.9.7→v1.0 plan correctly identified the visible symptoms, but
it was behind the branch in several important areas. Multi-source LiDAR,
folder ingest, the GPU arena, stable point identities, sparse edit undo,
ground/noise/rule classification, DTM contours, the LiDAR manager, and Rhai
automation had already landed. The actual v1 blockers were integration and
interaction defects: serial/uncached basemaps, attachment-owned CRS, no spatial
state for an empty drawing, fragmented measurement entry points, and no
dedicated selection/navigation affordances.

The plan also proposed optional PyO3/embedded CPython as a release gate. That is
not required for the requested workflows and would add installer/runtime risk,
so it remains a post-v1 option. Rhai and JSON automation remain the supported
embedded/headless paths for v1.0.

## Implemented for v1.0

### Basemaps

- Bounded native worker pool (2..8 workers) replaces sequential tile fetches.
- Provider/zoom/x/y disk cache supports PNG, JPEG, or WebP by file signature.
- Atomic temporary-file writes prevent partial downloads from becoming cache
  entries.
- Job ids, cancellation flags, and tab ids reject stale results.
- Live completed/failed/total progress appears in the status bar.
- `BASEMAP BOUNDS minx miny maxx maxy` establishes an underlay on an empty
  drawing; `BASEMAP BOUNDS CLEAR` removes the manual envelope.
- First underlay on an otherwise empty drawing auto-fits to the supplied bounds.
- `BasemapProjection::FromDrawing` is the default, with explicit Web Mercator,
  LAS, and EPSG overrides retained.

### Drawing CRS and working units

- `CRS <EPSG|LAS|UNSET>` validates against the bundled CRS database.
- Horizontal coordinate units are derived as meters, international feet,
  U.S. survey feet, or degrees.
- `WORKINGUNITS <METERS|CENTIMETERS|FEET|INCHES>` is independent when no CRS is
  set. With a CRS, it is normalized and locked to the CRS coordinate unit.
- CRS and working units are visible in the View ribbon and status bar.
- Sidecar schema v4 stores one drawing-owned spatial record independently of
  LiDAR attachments, including manual basemap bounds.
- Existing v2/v3 sidecars migrate in place; incompatible/stale saved unit pairs
  normalize on load.

### Measurement, selection, and navigation

- Existing `DIST`, `AREA`, and `MEASUREGEOM` display the active working unit.
- `VOLUME` totals selected complete, watertight mesh volumes.
- `POINTCLOUDMEASURE` snaps two screen picks to displayed points and reports 3D
  distance, horizontal distance, and delta-Z while highlighting both points.
- A Measure group is available in Annotate, LiDAR, and tool palettes.
- `SELECTTOOL` explicitly arms the existing click/window/crossing/lasso feature
  selection workflow and keeps the ribbon state visible.
- `NAVIGATOR` provides wheel zoom, left-drag pan, and Shift+left-drag orbit by
  reusing the validated viewport navigation path.

### Additional release-gate repairs

- A zero-sized point-arena shard now exits safely before the debug assertion,
  matching the function's contract and test.
- Seam-bounded analytic spheres receive a deterministic UV mesh fallback when
  the geometry kernel refuses adaptive tessellation, keeping render, volume,
  and primitive validation functional without discarding the analytic B-rep.

## Acceptance gates

- `cargo check --all-targets` succeeds.
- Workspace library/integration tests succeed, including basemap reprojection,
  cache reuse, sidecar v2→v4 migration, CRS unit derivation, point arena, and
  solid volume/triangulation.
- Release-mode Windows executable and thumbnail provider build successfully.
- WiX produces an x64 MSI carrying app and DWG/DXF icons, file associations,
  EULA, Start Menu entry, and upgrade behavior.
- MSI installs 1.0.0 locally and the installed executable version is verified.
- `main` is fast-forwarded so all v0.9.7 commits remain ancestors of v1.0.0.
- Published GitHub release `v1.0.0` includes release notes and Windows MSI/
  portable assets (plus CI-produced platform artifacts as workflows complete).

## Post-v1 backlog

- Cache size policy/eviction and HTTP conditional revalidation.
- Watched-folder production queues and richer per-job progress UI.
- Point-to-plane, point-to-surface, and cloud-to-cloud/RMSE measurements.
- Native COPC/E57 readers, raster DEM export, and breakline extraction.
- Optional embedded Python only after a separately validated runtime/installer
  design; it is not allowed to destabilize the v1 desktop package.
