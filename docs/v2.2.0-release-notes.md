# Open CAD Studio 2.2.0 — persistent terrain and project workspace

This release connects the existing terrain, CAD and LiDAR tools through two
dockable panels and restores downloaded elevation surfaces when drawings reopen.
It includes the terrain and searchable-tool interface introduced in 2.1.3.

## Project explorer

Open **Terrain & GIS → Project explorer** or run `PROJECTEXPLORER`.
The panel lists open drawings, attached point clouds, loaded GIS layers, the
active terrain surface, and up to 200 CAD objects. Click CAD objects to select,
highlight and zoom to them, or click a cloud/surface to fit its bounds. Drawing
links use stable identities even when tabs move. GIS entries identify the loaded
layer and its available commands; graphical GIS editing remains future work.

Both panels use the existing dock system: drag between edges, resize, pin,
auto-collapse, or close them. Panel visibility and layout survive restarts.

## Persistent terrain

Completed downloads write an immutable, compressed snapshot of the exact
elevation grid, point counts, source and units. Drawing `.ocspc` sidecars retain
the snapshot key, CRS and request settings. Reopening a saved DWG/DXF restores
the surface in a worker without network access or creating another mesh.
Elevation queries and draping then work against the restored grid.

Snapshots are checksum-verified and have bounded headers and grid dimensions.
They live in the user's OpenCADStudio `terrain_models` configuration directory;
when transferring drawings to another computer, transfer that directory too.
A missing/corrupt snapshot produces a visible message and can be rebuilt by
downloading the site again. Existing CAD mesh geometry stays in the drawing.
CRS changes and `TERRAIN REMOVE` clear the saved reference and reject late results.
Terrain arriving on an inactive tab adds its undoable mesh to the original
drawing's model space.

## Background jobs

Open **Terrain & GIS → Background jobs** or run `JOBSPANEL`.
The panel shows terrain and basemap downloads, LiDAR index builds,
classification, export/merge operations and drawing saves across all tabs.
Progress refreshes while visible. Cancellation is offered for operations that
support it and targets the exact job/document, including jobs in inactive tabs.
The panel also exposes the active spatial project's durable job history and
the command log. Classification and save operations that cannot safely stop
mid-commit are displayed without a Cancel button.

## Verification

Regression coverage includes exact terrain snapshot round trips, corruption
handling, drawing save/reopen without duplicate meshes, stale CRS result
rejection, terrain completion on an inactive document, undo, explorer selection
after tab reordering, and stale cancellation protection.

Pull requests and main-branch pushes now run the complete Windows workspace
test suite and a separate browser compilation check. Windows packaging retains
the existing upgrade identity, associations and bundled processing workers.

Fresh builds use the public `ramox81/cadcodec` mirror because the previous
`HakanSeven12/cadcodec` URL no longer resolves. The locked commit remains
`db73dab540dbfb690c93f4416014262e6cf7bf42`; the mirror preserves that exact Git
commit and tree. This repairs dependency downloads without upgrading the CAD
codec or changing its source.

This release implements the proposed project/terrain/jobs foundation. Direct
mesh sub-object editing, a graphical GIS editor, engineering surface analysis,
form-based workflow editing and specialized utility-corridor tools remain
subsequent development increments.
